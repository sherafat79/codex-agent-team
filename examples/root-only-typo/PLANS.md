# Plan template

## OBJECTIVE

State the typo to correct.

## SCOPE

Name the exact documentation file and text.

## INPUT EVIDENCE

Record the current text and requested correction.

## REQUIRED BEHAVIOR

Correct only the typo.

## CONSTRAINTS

Use the smallest safe diff.

## MUST PRESERVE

Preserve meaning, formatting, and nearby content.

## MUST NOT CHANGE

Do not rewrite unrelated documentation.

## ACCEPTANCE CRITERIA

The corrected text is present and the diff is scoped.

## ESCALATION CONDITIONS

Stop if the intended wording is ambiguous.

## EXPECTED OUTPUT

Report the changed file and diff-check result.
