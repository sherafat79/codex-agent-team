# Root orchestration

Root handles this fixture directly. If delegation becomes necessary, Root Orchestrator owns every
delegation, keeps `max_depth = 1`, and requires exclusive write ownership.

Every handoff must contain:

- OBJECTIVE
- SCOPE
- INPUT EVIDENCE
- REQUIRED BEHAVIOR
- CONSTRAINTS
- MUST PRESERVE
- MUST NOT CHANGE
- ACCEPTANCE CRITERIA
- ESCALATION CONDITIONS
- EXPECTED OUTPUT
